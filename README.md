# Matrix Calculator

A web-based Matrix Calculator built using Streamlit that supports a wide range of matrix operations and transformations commonly found in Linear Algebra.

## 🚀 Features
It currently supports -
### **Matrix Arithmetic**
Perform basic arithmetic operations on matrices:
 - Matrix Addition
 - Matrix Subtraction
 - Matrix Multiplication
### **Transformations & Decompositions**
1) Transpose – Compute the transpose of a matrix.
2) Inverse – Find the inverse of a square matrix (if invertible).
3) Determinant – Find the inverse of a square matrix (if invertible).
4) Rank  – Compute the rank of a matrix.
5) Null Space – Determine the null space (kernel) of a matrix.
6) Eigenvaluess – Calculate the eigenvalues of a square matrix.
7) LU Decomposition – Perform LU decomposition (Factorization into Lower and Upper triangular matrices).
8) Singular Value Decomposition – Compute the SVD of a matrix.

## ⚙ Technology Stack
- Python
- NumPy, SciPy, SymPy (for matrix operations)
- Pandas (for data handling)
- Streamlit (for interactive UI)
